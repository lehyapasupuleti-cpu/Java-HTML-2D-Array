# Java 2D Array Operations

This project demonstrates matrix operations using two-dimensional arrays in Java.

## Operations Covered

- Matrix Addition
- Matrix Subtraction
- Matrix Multiplication
- Element-wise Division
- Two-Dimensional Array Traversal
- Nested Loops

## Matrices Used

### Matrix A

8  6  
4  2

### Matrix B

4  2  
2  1

## Technologies Used

- Java
- HTML
- CSS

## Learning Outcome

Through this project, I practiced Java two-dimensional arrays, nested loops, matrix operations, array traversal, and basic HTML/CSS presentation.
