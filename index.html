Java 2D Array Operations

This project demonstrates matrix operations using two-dimensional arrays in Java.

Matrix A

8    6
4    2

Matrix B

4    2
2    1

Operations Covered

  • Matrix Addition
  • Matrix Subtraction
  • Matrix Multiplication
  • Element-wise Division
  • Two-Dimensional Array Traversal
  • Nested Loops

Java Code

public class Main {

    public static void main(String[] args) {

        int[][] A = {
            {8, 6},
            {4, 2}
        };

        int[][] B = {
            {4, 2},
            {2, 1}
        };

        int rows = A.length;
        int cols = A[0].length;

        int[][] sum = new int[rows][cols];
        int[][] sub = new int[rows][cols];
        int[][] mul = new int[rows][cols];
        double[][] div = new double[rows][cols];

        for (int i = 0; i < rows; i++) {

            for (int j = 0; j < cols; j++) {

                sum[i][j] = A[i][j] + B[i][j];

                sub[i][j] = A[i][j] - B[i][j];

                div[i][j] =
                    (double) A[i][j] / B[i][j];
            }
        }

        for (int i = 0; i < rows; i++) {

            for (int j = 0; j < cols; j++) {

                for (int k = 0; k < cols; k++) {

                    mul[i][j] +=
                        A[i][k] * B[k][j];
                }
            }
        }
    }
}
